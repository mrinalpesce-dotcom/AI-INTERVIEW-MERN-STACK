**InterviewIQ** is a full-stack MERN application that simulates realistic AI-driven mock interviews. Upload your resume, choose a role and interview mode (HR or Technical), and receive personalized questions generated by GPT-4o-mini. Each answer is evaluated in real time with detailed scoring across confidence, correctness, communication, and completeness — helping you prepare smarter for your next job interview.

---

## ✨ Features

### 👤 User-Facing
- **Google Authentication** — One-click sign-in via Firebase; JWT-based session management with HTTP-only cookies.
- **Resume Analysis** — Upload a PDF resume and the AI extracts your role, experience, projects, and skills automatically.
- **AI Interview Generation** — Get 6–8 tailored interview questions based on your profile, role, experience level, and interview mode (HR / Technical).
- **Real-Time Answer Evaluation** — Submit answers and receive instant AI-generated feedback with granular scoring (Confidence · Correctness · Communication · Completeness).
- **Timed Interviews** — Each question has a difficulty-adjusted time limit with a built-in timer page.
- **Interview History** — Browse all past interviews, review question-wise scores, and track improvement over time.
- **Detailed Reports** — View comprehensive performance reports with per-question breakdowns.
- **Credit System & Payments** — Purchase interview credits through Razorpay (Basic ₹99 · Pro ₹249 · Elite ₹499).

### 🔐 Admin Dashboard
- **Admin Overview** — At-a-glance platform statistics and metrics.
- **Customer Management** — View, search, and manage registered users with detailed individual profiles.
- **Activity Tracking** — Monitor user activities (logins, interviews, payments) in real time.
- **Analytics** — Platform-wide usage analytics and trends.
- **Audit Logs** — Complete audit trail of all system actions for compliance and debugging.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mrinalpesce-dotcom/AI-INTERVIEW-MERN-STACK.git
cd AI-INTERVIEW-MERN-STACK
```

### 2. Install Dependencies

```bash
# Root dependencies
npm install

# Client dependencies
cd interviewIQ/client
npm install

# Server dependencies
cd ../server
npm install
```

### 3. Configure Environment Variables

**Server** — Create `interviewIQ/server/.env`:

```env
PORT=8000
MONGODB_URL=mongodb+srv://<username>:<password>@cluster.mongodb.net/<dbname>
JWT_SECRET=your_jwt_secret_key
OPENROUTER_API_KEY=sk-or-xxxxxxxxxxxxxxxxxxxxxxxx
RAZORPAY_KEY_ID=rzp_test_xxxxxxxxxxxxxxxx
RAZORPAY_KEY_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

**Client** — Create `interviewIQ/client/.env`:

```env
VITE_SERVER_URL=http://localhost:8000
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
```

### 4. Seed the Admin Account

```bash
cd interviewIQ/server
npm run seed:admin
```

### 5. Run the Application

```bash
# Start the backend (from interviewIQ/server)
npm run dev

# In a new terminal — start the frontend (from interviewIQ/client)
npm run dev
```

The client will be available at **http://localhost:5173** and the API at **http://localhost:8000**.

## 🔌 API Endpoints

### Authentication
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/auth/google` | Google OAuth sign-in / sign-up |
| `POST` | `/api/auth/logout` | Log out and clear session cookie |

### Interview
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/interview/analyze-resume` | Upload & analyze a PDF resume |
| `POST` | `/api/interview/generate` | Generate AI interview questions |
| `POST` | `/api/interview/submit-answer` | Submit an answer for AI evaluation |
| `POST` | `/api/interview/finish` | Complete interview & get final scores |
| `GET` | `/api/interview/all` | Get all interviews for current user |
| `GET` | `/api/interview/:id` | Get a specific interview by ID |
| `DELETE` | `/api/interview/:id` | Delete an interview |

### Payments
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/payment/create-order` | Create a Razorpay payment order |
| `POST` | `/api/payment/verify` | Verify payment & credit user account |

### User
| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/user/current-user` | Get authenticated user's profile |

### Admin
| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/admin/auth/login` | Admin login |
| `GET` | `/api/admin/overview` | Dashboard statistics |
| `GET` | `/api/admin/customers` | List all customers |
| `GET` | `/api/admin/customers/:id` | Customer detail |
| `GET` | `/api/admin/activities` | User activity feed |
| `GET` | `/api/admin/analytics` | Platform analytics |
| `GET` | `/api/admin/audit-logs` | Audit trail |

## 🌐 Deployment

The application is configured for deployment on **Render**:

- **Backend**: Deploy `interviewIQ/server` as a Web Service  
- **Frontend**: Run `npm run build` from root (builds `interviewIQ/client`) and deploy as a Static Site  
- Set all environment variables in the Render dashboard  
- Update `VITE_SERVER_URL` to your deployed backend URL  
- Update `CLIENT_URL` in the server `.env` to your deployed frontend URL
